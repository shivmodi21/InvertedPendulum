03 / PROJECT NOTES

An interactive control experiment.

This lab simulates a cart-mounted inverted pendulum in your browser: the pole falls freely, a swing-up controller injects energy, and LQR feedback stabilizes it near the upright target. Tune physical parameters and controller weights, run the simulation, and follow cart position, pole angle, and applied force through the live view and synchronized charts. Nonlinear dynamics and numerical integration run on a Python backend; the badges below list the stack used to build and serve the experience.

Python NumPy SciPy Flask Matplotlib JavaScript
